# v0.3.1

## 修复与改进

- SDK 与打包 CLI 固定到 Codex Proxy RS v3.25.0 的提交 `05ba116eef849a0f4fa2d1940be82182bb2f7683`，工作台等待宿主 `next` 时暂停插件处理预算，返回后恢复剩余时间
- 增加真实插件子进程回归测试，覆盖 request、attempt 的透传与示例处理路径并发等待 `next` 超过 120 秒后正常完成
- 管理页面采用 `@codex-proxy/ui v0.4.0` 组件接口

## 升级说明

- 宿主与工作台插件需一起升级，最低宿主版本为 v3.25.0，包内兼容范围为 `>=3.25.0, <4.0.0`；单独升级宿主无法解除旧插件 SDK 的固定期限
- 请求总期限与取消继续由宿主独立控制，暂停 `next` 等待期间的预算不会解除这些约束
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及各自的 SHA-256 校验文件；选择与宿主运行平台一致的 `.tar.gz`
- 现有实例需在插件管理中安装并切换至新版本
