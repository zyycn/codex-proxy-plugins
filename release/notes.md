# v0.3.0

## 兼容性与改进

- 工作台迁移至中间件 v4，适配移除旧中间件接口的 Codex Proxy RS v3.23.0；请求与尝试阶段保留宿主原生 `fast_mode` 的默认、启用、禁用三种状态
- SDK 与打包 CLI 固定到宿主 v3.22.2 的提交 `705f0fad06667ad6aaf0ea162a869d2d3cfe39c2`，使用其中已提供的中间件 v4 合同
- 管理页面依赖升级至 `@codex-proxy/ui v0.3.2`

## 升级说明

- 最低宿主版本提升至 v3.20.0，包内兼容范围为 `>=3.20.0, <4.0.0`，需要清单 v2、通信协议 v2 和中间件 v4
- 原 v0.2.0 插件包使用中间件 v3，不能在宿主 v3.23.0 加载；升级宿主时请同时升级工作台插件
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及各自的 SHA-256 校验文件；选择与宿主运行平台一致的 `.tar.gz`
- 发布不会自动安装或启用插件，现有实例需在插件管理中安装并切换至新版本
