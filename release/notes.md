# v0.1.17

## 图片工作台

- 新增自然语言生图与多轮对话编辑：描述图片后直接继续提出修改要求，也可以围绕历史图片进行文字问答。
- 统一画布与对话区，桌面采用一屏等高布局，输入框固定在对话区底部；支持图片版本回看、参考图、画质与尺寸设置、取消和失败重试。
- 通过公开模型桥预热上游连接，正常续聊仅发送上一轮响应 ID 与新增消息，不重复上传历史图片。句柄明确失效且尚无语义输出时，使用保留的完整历史恢复一次。
- 失败、取消与重试只使用已成功提交的上下文；普通超时和上游错误不会自动重发，防止重复生成。
- 当前会话保存在页面内，刷新或离开图片页会清空。模型仍需处理累计上下文；单次请求上限 8 MiB，完整恢复超过上限时提示新建对话，历史达到 32 MiB 后阻止后续轮次。

## 图片上传适配示例

- 新增 `/v1/images/edits` 的 request 中间件示例，将 multipart 的 `image` / `image[]` 上传转换为宿主支持的 JSON `images[].image_url`，复用原有账号选择与上游调用。
- 支持 PNG、JPEG、WebP，最多 16 张图、multipart 正文最多 16 MiB；未支持的 mask、URL 输出等参数明确报错。JSON 请求及其他端点保持原有行为。
- 补充二进制与多图转换、非目标请求、输入拒绝、下游错误和取消传播的回归测试，并提供源码导航与调用示例。

## 开发支持

- 简化工作台 Vite 配置，由 Vite 生成 HTML 与资源引用，并保留宿主隔离页所需的经典脚本格式。
- SDK、打包器与 UI 依赖版本保持不变，新增示例无需修改宿主生产代码或增加插件权限。

## 升级说明

- 本版按示例仓库约定发布为预发行，安装时指定 `v0.1.17` 并允许预发行；宿主兼容范围调整为 `>=3.17.0, <4.0.0`，使用原生上游续接能力，通信协议保持 v1。
- multipart 适配在工作台的 `middleware` / `request` 绑定启用且请求匹配时自动生效，不需要演示标记。升级已有实例前请核对绑定范围；本版本不会自动升级或启用运行实例。
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及 SHA-256 校验文件。
