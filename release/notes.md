# v0.9.0

> [!IMPORTANT]
> 本版页面需要包含 UI v0.8.0 主题桥更新的宿主 `main` 构建，请与本次宿主更新配套使用
> 旧宿主仍使用 `cp` 主题变量，单独升级本版插件会缺少正确的主题样式

## 修复与改进

- 页面固定使用 UI v0.8.0，组件样式统一为 `z` 命名，跟随宿主新的主题命名空间桥同步颜色与字体
- 页面视口高度变量独立于主题前缀，图片工作台沿用宿主提供的可用高度
- 本地预览使用规范后的主题 API，组件动效与 Markdown 提示块随 UI 库更新

## 升级说明

- 本版不保留旧主题前缀别名，宿主与插件需要配套升级
- Rust SDK、RPC v7、中间件 v6 与持久状态格式保持不变
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及各自的 SHA-256 校验文件；选择与宿主运行平台一致的 `.tar.gz`
