# v0.7.0

## 修复与改进

- 适配 Codex Proxy RS v3.31.0 的中间件 v6，修复工作台源码联调时的作者清单校验失败
- SDK 与打包 CLI 固定到同一兼容提交，保持构建与打包合同一致
- 共享 UI 依赖固定到 v0.6.0 正式发布提交

## 升级说明

- 最低宿主版本提升至 v3.31.0，包内兼容范围为 `>=3.31.0, <4.0.0`；插件通信协议仍为 v5
- 仍使用中间件 v5 的宿主请继续使用工作台 v0.6.1；宿主升级至 v3.31.0 后，再安装并切换到本版本
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及各自的 SHA-256 校验文件；选择与宿主运行平台一致的 `.tar.gz`
