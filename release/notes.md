# v0.1.14

## 体验优化

- 组件库升级到 `@codex-proxy/ui` v0.2.0，改善选择菜单与弹出层的滚动跟随和尺寸变化定位。
- 前端依赖切换为固定 GitHub 标签，安装时构建组件库，并由锁文件固定实际提交；pnpm 固定为 12.6。

## 开发支持

- 支持作为宿主 `modules/plugins` 子模块开发，使用 `dev:source` 和 `build:source` 联调同一目录下的 UI 源码；普通开发与发布构建仍使用锁定依赖。
- 补充独立检出和宿主子模块两种开发方式，正式 SDK 与打包器仍固定到 `f770ba127d1293bb482921019e61cae7cb3b7de9`。

## 升级说明

- 本版按示例仓库约定发布为预发行，安装时指定 `v0.1.14` 并允许预发行；不会自动升级或启用运行实例。
- 宿主通信协议保持 v1，与 v0.1.13 的要求一致。提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及 SHA-256 校验文件。
