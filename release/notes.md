# v0.5.0

## 修复与改进

- 适配 Codex Proxy RS v3.29.0 的通信协议 v4 与入口请求上下文合同，使用中间件 v5、调度 v3，以及模型路由、入口认证、管理和观察能力 v2
- SDK 与打包 CLI 固定到宿主 v3.29.0 的同一发布提交，持续集成同时检查实际安装包构建
- 管理页面依赖升级到 `@codex-proxy/ui v0.5.0`

## 升级说明

- 最低宿主版本为 v3.29.0，包内兼容范围为 `>=3.29.0, <4.0.0`；升级宿主至 v3.29.0 时，工作台需安装并切换到本版本
- 宿主 v3.28.x 请继续使用工作台 v0.4.0，本版本不兼容其通信协议
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及各自的 SHA-256 校验文件；选择与宿主运行平台一致的 `.tar.gz`
