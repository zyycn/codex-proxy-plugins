# v0.1.11

首个独立发布的插件工作台预览版，使用固定版本 UI 安装包和公开 SDK 提交，可独立构建与安装。

- 提供摘要、翻译、改写、保存历史与网页取文的文本工作台，以及请求处理、账号和客户端认证等基础示例。
- 网页取文区分网络拒绝、解析失败和超时，使用简洁通知并在失败时保留原文。
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包与 SHA-256 校验文件。

## 兼容与安全

- 要求宿主版本 `>=3.14.0, <4.0.0`，支持清单 v3、通信协议 v4 和 SDK 0.4 对应能力；不适用于 `3.13.1` 正式宿主。
- 当前宿主能力可从 `codex-proxy-rs` 提交 `7cf3a5d84d8b528bf848f5e8303eece1e4bf6bad` 构建；插件处于预览阶段，不自动升级或启用运行实例。
- 插件是受信任本机进程，不是操作系统沙箱。网络、模型、账号、请求和公开入口权限需由管理员确认后使用。
- 安装对应平台的 `.tar.gz`，先核对同名 `.sha256`；源代码归档不是可安装插件包。
