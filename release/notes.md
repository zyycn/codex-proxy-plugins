# v0.6.0

## 修复与改进

- 适配 Codex Proxy RS v3.29.7 的插件通信协议 v5，SDK 与打包 CLI 固定到同一宿主发布提交
- 网页取文适配字节形式的 HTTP 请求头与响应头，拒绝无效 UTF-8 或非文本 Content-Type
- `next` 超时测试使用虚拟时钟，真实插件子进程继续验证握手、回调与退出

## 升级说明

- 最低宿主版本为 v3.29.7，包内兼容范围为 `>=3.29.7, <4.0.0`；宿主升级至 v3.29.7 后，工作台需安装并切换到本版本
- 宿主 v3.29.0–v3.29.6 请继续使用工作台 v0.5.0；本版本使用协议 v5，不兼容协议 v4 宿主
- 源码构建需要 Rust 1.99.1
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及各自的 SHA-256 校验文件；选择与宿主运行平台一致的 `.tar.gz`
