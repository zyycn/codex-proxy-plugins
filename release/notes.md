# v0.1.12

插件工作台预览版改用宿主内置的 OpenAI 与 xAI，通过已有客户端 Key 和模型体验插件扩展。

- 移除示例 Provider、模拟账号创建和相关页面，模型调用使用已有的真实账号与可用模型。
- 保留请求处理中间件、模型路由、账号调度、请求与用量观察、WebSocket 观察、客户端认证、管理页面及 CLI 扩展。
- 文本工作台继续提供摘要、翻译、改写、保存历史与网页取文；基础能力示例同步使用真实模型调用和请求记录。
- SDK 与打包器统一固定到 `687ebd0331846e155e0268cba390ccdbe6aaa887`。
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包与 SHA-256 校验文件。

## 兼容与安全

- 要求宿主版本 `>=3.14.0, <4.0.0`，支持清单 v3、通信协议 v4 和 SDK 0.4 对应能力；不适用于 `3.13.1` 正式宿主。
- 当前宿主能力可从 `codex-proxy-rs` 提交 `687ebd0331846e155e0268cba390ccdbe6aaa887` 构建；插件处于预览阶段，不自动升级或启用运行实例。
- 插件是受信任本机进程，不是操作系统沙箱。网络、模型、请求和公开入口权限需由管理员确认后使用。
- 安装对应平台的 `.tar.gz`，先核对同名 `.sha256`；源代码归档不是可安装插件包。
