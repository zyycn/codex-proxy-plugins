# v0.4.0

## 修复与改进

- 适配 Codex Proxy RS v3.28.0 的 `scheduler` v2 合同，工作台调度示例只选择当前可用的账号，没有可用候选时委托宿主内置调度
- 管理页面采用 `@codex-proxy/ui v0.4.1`，弹窗高度受视口约束，长内容可在弹窗内滚动
- SDK 与打包 CLI 固定到支持调度 v2 的同一宿主提交 `64c00f4adb08a155600ae84c4fc214c6533dbcd0`

## 升级说明

- 最低宿主版本为 v3.28.0，包内兼容范围为 `>=3.28.0, <4.0.0`；v0.3.1 工作台使用调度 v1，升级宿主至 v3.28.0 时需安装并切换到本版本
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及各自的 SHA-256 校验文件；选择与宿主运行平台一致的 `.tar.gz`
