# v0.1.13

插件工作台预览版接入新的宿主通信协议，修复启用插件后大请求可能触发 502、并影响后续请求的问题。

## 问题修复

- SDK 与打包器统一固定到 `f770ba127d1293bb482921019e61cae7cb3b7de9`，请求正文与控制元数据分别传输，不再受原有 1 MiB IPC 整帧上限影响。
- 普通请求按原始字节传递，保留全部 9 类能力示例；宿主不按演示标记绕过插件。单次调用的元数据校验失败不再关闭共享通信会话。
- 已验证 101 MiB 请求完整透传和真实模型 SSE 增量响应。处理器仍缓冲完整正文，实际可用请求大小与并发量取决于宿主及插件的内存；其他接口的资源预算保持不变。

## 升级说明

- SDK 重置为 `0.1.0`，清单版本与通信协议版本统一为 `1`，不保留旧协议兼容分支。
- 需配套使用包含上述提交或后续兼容实现的宿主；仅版本号满足 `>=3.14.0, <4.0.0` 不代表旧构建支持新协议。升级宿主后重新安装本版插件，旧插件包不能继续与新宿主通信。
- 本版为预发行，安装时指定 `v0.1.13` 并允许预发行。发布不会自动升级或启用运行实例。
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及 SHA-256 校验文件。安装对应平台的 `.tar.gz` 并核对同名 `.sha256`；源代码归档不是可安装插件包。
