# v0.8.0

> [!IMPORTANT]
> 本版要求 Codex Proxy RS `>=3.33.0, <4.0.0`，使用插件通信协议 v7；请先将宿主升级至兼容版本，再安装本版插件

## 修复与改进

- SDK 与打包工具统一更新至宿主 `v3.33.0` 的固定提交，适配 RPC v7 的挂起、恢复授权与回调消费确认
- 工作台的宿主回调使用新版 SDK 的协作调度，等待期间可让出执行名额，恢复处理前重新取得名额

## 升级说明

- 中间件能力版本保持 v6，工作台功能与持久状态格式不变
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及各自的 SHA-256 校验文件；选择与宿主运行平台一致的 `.tar.gz`
