# v0.2.0

## 工作台能力

- 将自然语言生图、多轮图片编辑、版本回看和参考图功能纳入正式发行；正常续聊使用原生响应 ID，句柄明确失效且尚无语义输出时才尝试一次完整历史恢复
- 保留 `/v1/images/edits` 的 multipart 上传适配，支持 PNG、JPEG、WebP 的 `image` / `image[]`，通过原有宿主账号选择和上游调用完成编辑
- 请求完成、用量及 WebSocket 响应观察统一使用 `observer` 能力，工作台同步展示新的观察事件
- 网页取文使用 SDK 托管的 HTTP 响应正文，统一流读取与关闭处理

## 构建与发布

- SDK 与打包 CLI 统一固定到可获取的宿主提交 `b37d7901441e123cb9126a6f9af4ff3321548d24`，修复旧依赖提交不可获取导致的 CI 构建失败
- 本版发布为正式版并更新 GitHub Latest，安装时无需允许预发行；发布流程继续支持带后缀的预发行版本
- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及对应 SHA-256 校验文件

## 升级说明

- 本版使用清单 v2、通信协议 v2、中间件 v3，与旧协议插件包及宿主不兼容，因此版本提升到 v0.2.0
- 宿主必须支持上述合同，并满足包内 `>=3.17.0, <4.0.0` 的版本范围；**v3.17.0 正式宿主仍使用旧协议，不能安装本版**。可使用宿主提交 `b37d7901441e123cb9126a6f9af4ff3321548d24` 或后续兼容构建，仅版本号满足范围并不足够
- 插件按受信任本机进程运行，安装时需确认完整信任；清单不再声明访问域权限，运行模型示例仍需已有可用 Key、模型及上游额度
- multipart 适配需启用覆盖相应请求的 `middleware` / `request` 绑定；不支持 mask 和 URL 输出等参数。图片会话保存在页面内，刷新或离开图片页会清空
- 发布不会自动安装、启用插件或升级宿主实例；使用对应平台的 `.tar.gz` 安装并核对同名 `.sha256`，源代码归档不是安装包
